CSCI Group Project II

Overview:
This submission contains two complete implementations to satisfy the project requirements. Both implementations retain the required filename within their respective subfolders.

Folder Structure:
1. /Manual_Initialization/
   - Implementation requiring external loading via a .load file and setting the instruction pointer to 0300.
   - Includes its own README detailing setup and execution instructions.

2. /Auto_Initialization/
   - Standalone implementation featuring built-in input validation (-32768 to 32767), character-by-character checks, labeled outputs, and direct execution without setup.
   - Includes its own README with execution details and test cases.

Please consult the individual README files inside each subfolder for specific setup and run instructions.
